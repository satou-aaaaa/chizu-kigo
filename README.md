# 地図記号よみ

地図記号を見て、何の場所かを当てる1日5問のゲーム。そろばんの形は税務署、刺股（さすまた）の形は消防署。形のわけを知ると、はじめて見る記号でも見当がつきます。

- 遊ぶ: https://satou-aaaaa.github.io/chizu-kigo/
- 今日の5問（記号よみ2・記号さがし2・形のわけ1）はだれでも同じで1日1回。上級（形のわけ3問・ヒントなし）、練習（何度でも）、とことん（何問続けて一度で解けるか）、集めた記号が並ぶ「記号帳」があります。
- 正解すると、記号の形のわけ・生まれた年と、国土地理院のページへのリンクが出ます。ヒントは「なかま」→「選び肢を2つにしぼる」の2段です。
- 文字の大きさは3段。見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）もあります。記号は色を使わず線だけで描いています。
- 機種を変えるときは「引き継ぎ」で、記録をコードと QR にして移せます。

## 記号の出どころと研究

- 記号の名前・形のわけ・生まれた年は、国土地理院の [地図記号一覧](https://www.gsi.go.jp/kohokocho/map-sign-tizukigou-2022-itiran.html) と各記号のページ、[新しく生まれた地図記号](https://www.gsi.go.jp/kohokocho/kohokocho40074.html) で確かめています。地図記号はだれでも自由に使えます（[国土地理院 FAQ](https://www.gsi.go.jp/kohokocho/FAQ3.html) Q3.9）。
- 記号の絵は、このゲームのために線で描き直したものです。細かい形は国土地理院のページで確かめられます。
- 思い出して答える練習は読み直すより記憶に残りやすいことが知られています（[Adesope ほか 2017](https://doi.org/10.3102/0034654316689306)）。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を使うため、ページを開くと Google に接続し、IP アドレスが届くことがあります（端末に文字を保存したあとでも、ブラウザが先に接続することがあります）。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（記号の名前と答えは入りません）。
